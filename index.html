Direct Download


Currently Windows and Linux are available in their respective app stores, or you may download them here directly.
 
  • macOS (Universal DMG) SHA-256 checksum
  • Windows (x64 Setup) SHA-256 checksum
  • Linux (AMD64 Snap) SHA-256 checksum

To verify a download, save the checksum file in the same folder as the installer and open a terminal in that folder.

On Windows, run Get-FileHash -Algorithm SHA256 [name].exe
in PowerShell and compare the result with the hash in the checksum file.

On macOS, run shasum -a 256 -c [name].dmg.sha256

On Linux, run sha256sum -c [name].snap.sha256
